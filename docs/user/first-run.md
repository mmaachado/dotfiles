# First run

After `./install.py kshell enable`, KShell starts with the session.

- **The bar** sits on the left: virtual desktops and the active window at the
  top, your apps in the middle, then power, settings, status icons and the
  tray at the bottom. Right-click an app to pin it.
- **The notch** at the top shows the time, what's playing and new
  notifications. Hover it, or press ++meta+alt+d++, for the dashboard:
  calendar, media, quick settings and notifications.
- **The launcher** opens with ++meta++ or ++meta+space++. Type to search;
  right-click an app to pin it.
- **Wallpapers** go in `~/Pictures/Wallpapers`; ++meta+w++ opens the picker.
  With colours set to *Wallpaper*, the whole desktop takes its colours from
  the one you pick.
- **Settings** open from the gear in the bar.

KShell restarts with `kshell restart`; `just log` (in the repo) shows its
latest warnings and errors.
