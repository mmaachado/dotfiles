# Roadmap

## Next

- **Project tooling**: just, git hooks, commit checks, the release script,
  this portal *(in progress)*.
- **Screenshots like macOS** *(in review)*: ++meta+shift+3++,
  ++meta+shift+4++ and ++meta+shift+5++ with a capture toolbar, screen
  recording, a floating thumbnail, and **droid Markup** (Kotlin) for
  annotations.
- **Clipboard like Windows 11** *(in review)*: images in the history,
  pinned items, sync with your phone through KDE Connect.
- **Phone mirroring like macOS** *(in review)*: **droid Phone** (Kotlin),
  an Android front end for scrcpy with Wi-Fi pairing by QR code, audio and
  file drop.
- **AI usage** *(in review)*: [ai-usagebar](https://github.com/akitaonrails/ai-usagebar)
  as a ring beside the tray, with each provider's quota in a popup.

## Later

- **droid Settings** as a Kotlin app, replacing the QML settings window.
- **A graphical installer** in Kotlin.

## Someday: droid from scratch

A desktop built from the ground up with Android's layout, in the spirit of
[helloSystem](https://hellosystem.github.io): its own session and settings,
not a layer on top of Plasma. It's an idea, not a plan yet; the
[architecture](dev/architecture.md) page explains why droid is built on
Plasma today.
