# droid

**A Plasma-based Quickshell desktop, with Android's look.**

[Install](user/install.md){ .md-button .md-button--primary }
[What's new](releases.md){ .md-button }

</div>

droid keeps **KDE Plasma** underneath (KWin, the session, settings, power,
devices, the wallpaper and desktop widgets) and replaces its panels with
**KShell**, a shell built with [Quickshell](https://quickshell.org). On top
come Android's design pieces: Material 3 colours taken from your wallpaper,
spring motion, Google Sans, and Material Symbols system icons from
[droid-icons](https://github.com/mmaachado/droid-icons).

Strictly speaking droid is a *desktop shell*: KWin stays the window manager
and Plasma the environment. See [Architecture](dev/architecture.md).

<div class="grid cards" markdown>

- **A bar on any edge**: left, right, top or bottom, split around the notch or the launcher.
- **The notch**: a dynamic island for the time, music and notifications that opens into the dashboard.
- **Multiple monitors**: arrangement, orientation, primary display and a wallpaper per display.
- **Your colours**: Material 3 from the wallpaper or theme, for the shell, Plasma, Qt/GTK apps and kitty.

</div>

The current series is **1.x Cupcake**. See [Releases](releases.md).
